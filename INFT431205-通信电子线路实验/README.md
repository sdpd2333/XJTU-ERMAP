## 使用说明

先查看对应实验指导材料，再阅读报告。无线话筒目录中的日期属于原始文件命名，元件选型、下单要求和提交格式需要与当前课程要求核对。

`.rar` 需要支持该格式的解压工具；旧版 `.ppt`、`.xls` 建议用兼容的 Office 软件打开。原始工程资料和最终效果图应配套使用。
