# 资料使用指南

[返回项目首页](../README.md)

## 获取与查找

根目录按 `课程代码-课程名称` 分类，各课程的 `README.md` 提供实验入口。文件夹编号沿用原始资料，不能据此推断实验内容是否完整。

- 阅读单份文件：进入对应文件页面下载，或使用 GitHub 支持的预览。
- 下载全部资料：使用 **Code → Download ZIP**，或执行根 README 中的浅克隆命令。
- 查找内容：优先按课程代码、实验编号和文件名搜索。Word、PDF、压缩包等文件需要下载后使用相应软件检索正文。

## 软件与硬件

| 资料类型 | 打开或运行方式 | 注意事项 |
| --- | --- | --- |
| `.docx` / `.pptx` / `.xlsx` | 兼容的 Office 软件 | 模板、字体和公式在不同软件中可能有显示差异 |
| `.pdf` | PDF 阅读器 | 按课程说明核对指导书和报告版本 |
| `.m` | MATLAB | 先切换到该实验的工作目录，并检查工具箱和输入数据 |
| `.mlx` | MATLAB 实时编辑器 | 与同目录函数、音频及数据配套使用 |
| `.slx` | MATLAB / Simulink | 部分通信模型需要硬件支持包和 SDR 设备 |
| `.mat` | MATLAB `load` / `whos -file` | 历史文件的变量名和实验参数需要核对 |
| CC3200 工程 | CCS、CC3200 SDK 与实验板 | 查看[短距离无线通信说明](../INFT532705-短距离无线通信专题实验/README.md) |
| 51 单片机 C 文件 | 匹配的 C51 工具链与实验板 | 查看[电子系统设计基础说明](../INFT533605-电子系统设计基础/README.md) |

仓库中的工程分别面向不同课程，不提供全库统一构建命令。通用仓库检查通过，表示目录与维护约定通过检查，不表示所有实验已在目标设备运行成功。

## MATLAB 使用顺序

1. 从课程说明找到入口脚本，查看脚本顶部参数与依赖。
2. 将 MATLAB 当前文件夹设为该实验目录，添加必要的辅助函数目录。
3. 按指导书解压音频或准备数据文件，先执行 `whos -file 文件名.mat` 查看已有变量。
4. 用较小的数据规模确认流程，再按实验要求设置完整参数。
5. 记录 MATLAB 版本、工具箱、随机种子、采样率、信噪比及调制方式，核对结果的单位和坐标轴。

多个通信示例存在同名函数，因此不要对整个仓库执行 `addpath(genpath(...))`。切换实验后，如果调用了错误版本，可用 `which 函数名 -all` 查看实际解析到的路径。

部分脚本在当前目录保存同名 MAT 文件或音频，建议在工作副本中运行，或先备份需要保留的结果。新修改的 V-BLAST 和性能对比脚本将结果写入各自的 `results/` 目录，保存的 `rng_state` 可用于恢复仿真开始前的随机数状态。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 找不到 WAV / MAT 文件 | 核对当前文件夹、解压后的层级和脚本中的文件名 |
| 提示函数不存在 | 检查配套函数目录、工具箱和硬件支持包是否齐全 |
| 中文注释乱码 | 部分历史源文件采用 GBK；先检查编辑器编码，避免批量转换整个资料库 |
| 图像与历史报告不完全一致 | 对照随机种子、样本量、软件版本、输入数据和参数 |
| CCS 报 SDK 资源不存在 | 修正工程路径变量，确保链接资源指向本机 SDK |
| CCS 找不到 `network_config.h` | 按课程说明从示例配置复制本地配置，并保留工程间的目录关系 |
| 代码编译成功但硬件无响应 | 对照实验板地址映射、引脚、时钟、串口和下载设置 |

仍无法解决时，按[贡献指南](../CONTRIBUTING.md)提交复现信息。
