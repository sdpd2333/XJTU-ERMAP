## 使用说明

先阅读指导书，再填写相应模板。需要使用 Quartus Prime 的实验，可先查看 `2/Quartus Prime软件使用.pdf`，软件版本和器件型号以实验板及课程要求为准。

当前目录以指导书和模板为主，未单独收录 Verilog 源码或 Quartus 工程。模板中的内容与格式应按本次实验要求核对。
