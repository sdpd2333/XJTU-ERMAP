## 使用说明

用 MATLAB 打开 `.mlx` 实时脚本，并将当前文件夹切换到相应实验目录。实验 2 的辅助函数和实验 4 的音频需要保留在配套目录中。

滤波与信号分析函数可能需要 Signal Processing Toolbox，具体依赖以脚本调用及 MATLAB 提示为准。图片是已保存的结果，不能代替重新运行和核对参数。辅助函数中的原作者署名应保留。
