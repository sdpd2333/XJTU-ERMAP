## 使用说明

- 使用 MATLAB；重采样、滤波器设计、零极点绘图等脚本涉及 Signal Processing Toolbox。
- 实验 1 的音频来自 `document/samples.zip`。解压后找到 `7noise.wav` 和 `trip.wav`，将其所在目录加入 MATLAB 路径，再将当前文件夹切换到 `lab1`。不要把整个仓库递归加入路径。
- `lab1_1.m`、`lab1_2.m` 采用直接频谱求和，默认取最多 40000 个样本，计算量较大；先用少量样本理解流程再扩大计算规模。
- 实验 2 脚本内含历史测量值。提交自己的报告时，应替换为本次实验数据并核对归一化频率轴。
- 音频处理输出使用 `processed_audio_*.wav` 命名；重复运行会更新同名输出。
