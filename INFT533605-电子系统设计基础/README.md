## 使用说明

源文件使用 Keil C51 风格的 `reg51.h`、`absacc.h`、`code` 和 `XBYTE`，需要匹配的 8051 工具链及实验板。仓库未包含 Keil 工程文件，需自行新建工程并添加源文件。

- `0x8000` 用于位选 / 键盘访问，`0x9000` 用于段码输出；请先核对实验板的地址映射。
- `stu` 为八位显示内容，`SEG` 和 `duan` 分别为位选表与段码表。
- 主循环滚动显示八位数字；延时由循环实现，显示速度取决于时钟和编译器设置。
- `getkeycode()` 返回 0—15 的有效键值，16 表示无有效按键。当前主循环尚未接入按键切换模式，原示例的这一限制仍然保留。

代码已为位选索引和无效键值增加边界处理。主机上的编译与逻辑检查不能代替在目标实验板上验证显示、消抖及电气时序。
