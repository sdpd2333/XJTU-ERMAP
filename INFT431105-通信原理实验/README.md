## 使用说明

MATLAB/Simulink 工程需要按具体示例配置 Communications Toolbox 和相应的 SDR 硬件支持包。先阅读指导书，再打开对应工程；一次只将一个示例目录加入 MATLAB 路径，避免同名收发函数相互遮蔽。

### 同步实验的两个版本

- `3/example_s/` 为一组完整示例。
- `3/3/example_s/` 是另一份历史副本，其中 `source_code/bpsk_demo.m` 和 `source_code/rx_package_search.m` 与前者不同；`3/3/` 还保留了独有截图。

两份源码均保留，选择其中一个版本使用。`slprj/` 是运行模型时生成的缓存，重新运行时由 Simulink 建立。

### 差错控制脚本的适用范围

`2/crc74.m` 和 `2/jiema74.m` 使用固定的 2048 位实验帧及截断、补零逻辑，文件名中的 `crc74` 对应这里的 (7,4) 编码实现。它们不是任意长度数据的通用编解码接口；改变帧长时需要一并调整模型与脚本。
