# XJTU-ERMAP

**西安交通大学实验报告互帮互助项目**
Xi'an Jiaotong University Experimental Report Mutual Assistance Project

这里整理了西安交通大学信息工程相关课程的实验报告、指导书、代码、课件和实验记录。希望这些资料能帮助你提前理解实验、定位问题，把更多时间用于动手实践和独立思考。

项目由西安交通大学 2022 级信息工程专业学生发起，欢迎同学们补充资料、修正错误，也欢迎记录不同学年的课程变化。

## 从这里开始

1. 在下表按**课程代码或课程名称**找到资料，进入课程说明查看实验入口。
2. 先读当年的实验要求，再对照报告、代码与数据。目录中的历史资料可能与当前教学安排不同。
3. 运行代码前阅读[使用指南](docs/USAGE.md)，确认数据文件、工具箱和硬件环境。

下载整个仓库：在 GitHub 点击 **Code → Download ZIP**，或执行：

```bash
git clone --depth 1 https://github.com/sdpd2333/XJTU-ERMAP.git
```

只需要个别文档时，可进入文件页面下载。找不到资料或发现问题时，请[提交 Issue](https://github.com/sdpd2333/XJTU-ERMAP/issues/new/choose)，附上课程代码和具体路径。
